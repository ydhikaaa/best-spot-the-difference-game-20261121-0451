**Double Vision** is a complete spot-the-difference game for the make.fun
bounty [“Make the best spot the difference game”](https://make.fun/bounty/best-spot-the-difference-game-20261121-0451).
Two near-identical pictures sit side by side; eight details differ between
them. Find all eight to clear the scene — six scenes, 48 differences, and
the hiding gets sneakier every scene.

Everything is original and self-drawn: the scenes are flat-vector canvas
paintings generated by the game's own code (no image assets), and every
sound is synthesized live with WebAudio (no audio files). The game is a
static site — open `game/index.html` in a desktop browser and play; there
is no build step and it makes no network requests.

## How to play

- Click a difference in **either** picture to ring it on both.
- A find scores **100 points** plus a streak bonus (consecutive finds) and a
  speed bonus. A wrong click costs **15 points and 3 seconds** and breaks
  the streak.
- Each scene has a countdown and a **par time**: finish under par for a
  +150 bonus, plus 2 points per second left on the clock.
- **Hints:** 3 per scene, 40 points each — a pulse rings an unfound
  difference for a moment.
- **Magnifier:** a 2× loupe that follows your cursor over either panel.
- Run out of time and you may retry the scene (its points roll back).

### Controls

| Input | Action |
| --- | --- |
| Mouse click | Mark a difference |
| Mouse hover | Move the magnifier loupe |
| `H` | Hint |
| `M` | Magnifier on/off |
| `P` | Pause |
| `R` | Restart scene |
| `Enter` / `N` | Start / next scene |

## The scenes

1. **Moonlight Night Market** — lanterns, fruit stalls and one very calm cat.
2. **Coral Reef Post Office** — undersea mail, delivered by an eight-armed postman.
3. **Sky Train Station** — the 5 o'clock to the clouds is now boarding.
4. **Desert Caravan Camp** — tea at sunset, somewhere past the last dune.
5. **Winter Owl Cabin** — a warm window, a cold night, a watchful owl.
6. **Clockwork Garden** — everything here blooms on gears; mind the teeth.

## Layout of this repository

- `main.ts` — the hand-in program (Node 22, standard library only): copies
  `game/` and `screenshots/` to the output directory and writes
  `dossier.json` with the vendored make.fun library.
- `serve.ts` — a tiny static server for local play-testing
  (`node serve.ts`, then open http://localhost:8080).
- `game/index.html` — the page: HUD (scene, score, streak, remaining
  counter, timer, par), the two panels, controls and overlays.
- `game/src/scenes.js` — the campaign as data: six scenes × eight
  differences, each with its scene-space position and label.
- `game/src/render.js` — the painters: every scene drawn twice from the
  same code (original + altered), plus find markers, hint pulses and
  mistake marks.
- `game/src/game.js` — the state machine: scoring, streaks, timer, hints,
  phase changes, and the demo states (`?scene=N&found=K`) the screenshots
  were taken in.
- `game/src/input.js` — panel clicks, the magnifier loupe, keyboard.
- `game/src/audio.js` — WebAudio-synthesized cues; no audio files.
- `game/src/main.js` — bootstrap and button wiring.
- `screenshots/` — four real renders of the running game (cover first).
- `vendor/makefun-game.ts` — the kit's dossier library, vendored unchanged.

## Handing it in

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

Run it twice and the outputs are byte-for-byte identical.
